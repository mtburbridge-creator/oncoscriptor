# OncoGenik

A pipeline that turns a patient-facing oncology video idea into a script, a talking-points outline, and an HTML slide deck. Three agents share this repo. You review in a web UI, Claude writes, Hermes researches forums and literature and generates images.

- `docs/ENGINE_DESIGN.md` is the architecture and build order.
- `docs/HERMES_CONTRACT.md` is what Hermes reads and writes.
- `slides/studio/` is Slide Background Studio, the deck generator, merged from its own repo.
- `Basic outline.drawio.html` is the original flow diagram.
