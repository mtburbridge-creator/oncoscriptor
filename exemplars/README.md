# Exemplars

Approved finals from finished projects. The `learn` skill copies them here when a project reaches `done`:

- `<slug>-script.md` is `projects/<slug>/script/final.md`
- `<slug>-outline.md` is `projects/<slug>/outline/final.md`
- `<slug>-prompts.json` is `projects/<slug>/images/prompts.json` filtered to the prompts whose image the owner approved

The `draft`, `outline`, and `prompts` skills read this folder before writing, as examples of what the owner has already accepted. They imitate structure, tone, section length, and citation style. They never copy sentences, and they never treat an exemplar as a source of medical facts for a different topic: every claim in a new script still comes from that project's own `research/sources.md`.

Nothing here is edited by hand except to delete an exemplar the owner no longer wants used. When the folder is empty, the draft skills fall back to `guidelines/` alone.
